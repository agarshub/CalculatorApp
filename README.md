# Calculator App (Java)

A beginner-friendly calculator application built in Java as part of my Java learning journey.

This project was not built in a single step. It evolved through multiple versions, with each version introducing new Java concepts and software engineering practices.

---

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Input Validation
* Exception Handling
* Menu Driven Interface
* Reusable Input Methods
* Division by Zero Protection

---

## Technologies Used

* Java
* Scanner Class
* Exception Handling
* Object-Oriented Programming (OOP)
